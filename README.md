# Juegos didácticos de finanzas

Juegos interactivos para repasar Expected Shortfall, backtesting y stress testing.

## Enlaces

- Demo en Vercel: https://risk-arcade-online-6nwjxjpm8-72949190s-projects.vercel.app
- Versión multijugador con salas: https://risk-arcade-online.perky-jelly-3893.chatgpt.site

El archivo `index.html` contiene la interfaz de los juegos. La versión multijugador utiliza el backend de Sites para crear códigos de sala, admitir hasta tres jugadores y permitir que el creador observe como espectador.
